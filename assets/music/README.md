# 🎵 Şarkı dosyası

Bu klasöre, kullanmaya yetkili olduğun **wanna-be-yours.mp3** dosyasını ekle.

Örnek yol: \`assets/music/wanna-be-yours.mp3\`

Arctic Monkeys'in "I Wanna Be Yours" kaydı telifli olduğu için dosya burada dağıtılmıyor. Kayıt/stream servisinden alınan erişim bağlantıları genellikle web sayfasında doğrudan müzik dosyası olarak oynatılamaz; uygun lisanslı ve tarayıcının çalabileceği ses dosyasını kullan.

Dosya bulunduğunda \`index.html\` içindeki \`<audio loop>\` öğesi tekrarlı çalar. Tarayıcıların sesli autoplay politikası yüzünden ilk yüklemede çalma **garanti edilemez**; bu durumda kullanıcı etkileşimi gerekir.
